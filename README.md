# نظام مطابقة فواتير المشتريات والجرد الذكي اللحظي 📦⚡
### Invoice Matcher & Real-Time Mobile Stocktake System

نظام متكامل لإدارة ومطابقة فواتير المشتريات، باركودات الأدوية والأصناف، والجرد المستودعي اللحظي مع مزامنة فورية بين أجهزة الكمبيوتر والموبايل عبر شبكة محلية أو نطاق سحابي **Cloudflare**.

---

## 🌟 الميزات الرئيسية (Key Features)

1. **جرد مستودعي لحظي متزامن (Real-Time Mobile Stocktake)**:
   - مسح سريع للباركود العادي (1D) وكود الاستجابة السريعة (QR) وباركودات الداتا ماتريكس الدولية (GS1 DataMatrix).
   - تحكم كامل من الموبايل تماماً مثل شاشة الكمبيوتر (إضافة مستودعات، تعديل الكميات +1 / -1، حذف، بحث، وترحيل الجرد).
   - مزامنة فورية لحظية (Instant Real-time Sync): أي مسح أو تعديل على الموبايل يسمع فوراً على الكمبيوتر بدون إعادة تحميل الصفحة، والعكس صحيح!

2. **ربط فوري عبر سحابة Cloudflare (Cloudflare Tunnel)**:
   - تشغيل بنقرة واحدة عبر دومين مشفر بـ HTTPS مجاناً من Cloudflare.
   - إمكانية الجرد من الموبايل من أي مكان (سواء عبر شبكة 4G/5G أو من خارج المستودع).
   - توليد كود QR تلقائي على شاشة الكمبيوتر لمسحه بالموبايل والبدء فوراً.

3. **مطابقة الفواتير الذكية (Invoice Matching)**:
   - استيراد ومطابقة فواتير المشتريات من ملفات PDF أو صور أو إكسيل.
   - محرك OCR متطور وفحص تلقائي للكميات وتواريخ الصلاحية والتشغيلات (Batch & Expiry).

4. **تصدير وطباعة تقارير احترافية**:
   - تصدير كشوفات الجرد والفروقات والنواقص إلى ملفات Excel منسقة باللغة العربية (RTL).
   - إمكانية طباعة تقارير الجرد المباشرة وكشوفات النواقص.

## 🚀 طريقة التشغيل (Quick Start)

### 1. التشغيل المحلي العادي (Local PC & WiFi):
```bash
# تشغيل البرنامج محلياً
python run.py
# أو تشغيل الملف المباشر:
run_app.bat
```

### 2. التشغيل مع دومين Cloudflare والمزامنة من أي مكان:
```bash
# تشغيل البرنامج مع نفق Cloudflare Tunnel المشفر:
run_with_cloudflare.bat
```
سيقوم البرنامج بتشغيل السيرفر وإنشاء رابط Cloudflare فوري (HTTPS)، ويعرض كود QR في شاشة البرنامج للمسح مباشرة من الموبايل.

## 📱 استخدام شاشة الجرد من الموبايل
- افتح الرابط على هاتفك، أو امسح كود QR من زر "الربط مع الموبايل" في واجهة الكمبيوتر.
- يمكنك استخدام:
  - **الماسح الضوئي بالكاميرا**: لمسح الباركودات بشكل متتالي مع صوت تنبيه واهتزاز.
  - **كشف الجرد**: للاطلاع على الأصناف، زيادة ونقصان الكميات، ومتابعة الفروقات.
  - **دليل الأصناف**: لإضافة الأصناف يدوياً والبحث في الكتالوج.
  - **التحكم والإغلاق**: لترحيل الجرد أو تصدير إكسيل من الموبايل مباشرة.

## ☁️ التشغيل السحابي الدائم (بدون الحاجة لتشغيل الكمبيوتر)
- رابط البرنامج الثابت: **https://rambfe.pages.dev** (يتحول تلقائياً لشاشة الموبايل عند الفتح من هاتف، و `?desktop=1` لفتح شاشة الكمبيوتر).
- كل الوظائف تعمل من الرابط: الجرد، الأصناف، الفواتير، المرتجعات، رفع المخزون، تصدير كل ملفات الإكسيل، استيراد كتالوج الأصناف، واستيراد ملفات الفواتير (Excel/CSV/TXT).
- **الصيدليات:** شريط أعلى كل شاشة للتبديل بين الصيدليات وإضافتها؛ لكل صيدلية استوراتها ومخزونها وجردها وفواتيرها المستقلة، ودليل الأصناف مشترك.
- **المزامنة اللحظية:** اتصال WebSocket دائم بين كل الشاشات (أقل من ثانية).
- البيانات محفوظة في **Cloudflare D1** الدائمة (`rambfe-db`). برنامج الكمبيوتر اختياري ويقرأ ويكتب في نفس قاعدة البيانات.
- ملف `data/cloud_admin_token.txt` (سري، لا يُرفع على GitHub) مطلوب فقط لمزامنة برنامج الكمبيوتر المحلي مع السحابة.
- كود السحابة في مجلد `cloud/`، والنشر: `sh cloudflare-pages/deploy.sh`، ومركز المزامنة اللحظية: `cloud/realtime`.
